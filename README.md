# `> ./recap-generator`

Weekly study recap cards for Instagram, in a terminal × dark academia style.
Type your week, pick a background photo, download a 1080 × 1440 PNG.

**Try it:** https://mmilymary.github.io/recap-generator/

```text
> git status: active_student
> location: week_39/recap.md

// TOPICS COVERED
>> [math]          Contribution margin calcs – exam on Monday
>> [it_basics]     Exam 19/20 – course done, coding next!
```

## Features
- Live preview while you type
- Topics with tags, add and remove rows
- Four retro-ish monospace fonts: Courier Prime, VT323, Space Mono, JetBrains Mono
- Your own background photo + darkness slider
- Text shrinks automatically if it doesn't fit
- Remembers your last recap in the browser
- Download as PNG

## Built with
Plain HTML, CSS and JavaScript · `<canvas>` · Google Fonts · GitHub Pages
